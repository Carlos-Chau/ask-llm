# Ask-LLM Chrome Extension
This extension allows user to ask LLM by 1-click on mouse3 button (scroll-wheel) 🖱️ 

LLM is served by HuggingFace Inference Provider  🤗

## Demo
![demo.gif](demo.gif)

## How-to-install
- **Manage Extension**: Settings >> Extensions >> Manage Extension
- **Enable Developer Mode**: toggle in top-right corner
- **Install Extension**: Click 'load unpacked' (top-left), select folder 'ask-llm' (this folder)
- **Verify Installation**: 'Ask LLM' now is in Manage Extension page
